# Чистый метр — прототип лендинга дезинфекции и клининга

React 18 + Vite 6 + Tailwind CSS 4, карта на Leaflet, графики на Recharts. Все данные в прототипе демонстрационные (mock). В интерфейсе они помечены жёлтыми бейджами «демо-данные».

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

Нужен Node.js 18+ (лучше 20+). Карте нужен интернет: подложка грузится с CARTO и OpenStreetMap.

Как проверить сценарии вручную:
- **Ошибка отправки формы:** укажите телефон, который заканчивается на `0000`.
- **Антиспам:** если заполнить скрытое поле `website` или отправить форму быстрее чем через 2,5 с после загрузки, сайт покажет «успех», но заявка не уйдёт.
- **Проверка адреса:** введите метро или город, например «Профсоюзная», «Митино», «Химки». Можно и просто кликнуть в любую точку карты.

## 1. Концепция и допущения

**Концепция:** «Сначала смотрим, потом считаем». На сайте почти нет обещаний про чистоту. Вместо них три прозрачных механизма: смета оценщика с фиксированной ценой, контрольные АТФ-замеры до и после, а также все отзывы подряд, включая низкие. Главный экран построен вокруг образа документа (сметы), а не стоковой фотографии.

**Допущения** (проверьте и замените, если они неверны):
1. Регион — Санкт-Петербург, включая пригороды в составе города.
2. Выезд оценщика в пределах КАД бесплатный. За КАД (Пушкин, Колпино, Петергоф и др.) стоит 700 ₽ и засчитывается в заказ.
3. Оценщик получает фиксированную оплату за выезд, а не процент с продаж. Из этого следует фраза «оценщик не навязывает услуги». **Если это не так, уберите эту формулировку.**
4. Оплата после приёмки, без предоплаты. Гарантия — бесплатная переделка в срок от 24 часов до 7 дней.
5. Компания подала уведомление о начале деятельности по дезинфекции в Роспотребнадзор, работает только со средствами, у которых есть госрегистрация или декларация ЕАЭС, и застраховала ответственность.
6. Лимит — 18 выездов оценщиков в день. Это и есть «дефицит», и показывается он честно: только реально свободные окна.
7. Сезонное предложение «−10% на дезинфекцию до 30.11.2026». После этой даты блок автоматически скрывается.

**Вопросы к заказчику:**
1. Название, реквизиты, телефон, реальные цифры: рейтинг, число объектов, год основания.
2. Бесплатен ли выезд оценщика и в каких границах?
3. Как оплачивается работа оценщика? От этого зависит формулировка про «не продавец».
4. Какие документы есть: уведомление, свидетельства на средства, страховка, удостоверения мастеров?
5. Есть ли реальные отзывы с фото, где клиенты дали согласие на публикацию, и замеры АТФ?

**Путь пользователя.** Hero сразу даёт две дороги:
- если человек уже решился, он нажимает «Вызвать оценщика» и попадает в форму;
- если хочет сначала понять, он идёт через «Рассчитать стоимость» в калькулятор, затем на карту и в форму.

Что пользователь выбрал в калькуляторе (объект, услугу, площадь, вилку цены) и на карте (район, день, слот), автоматически подставляется в форму. Это работает на принцип приверженности: человек уже сделал часть работы, и форма это показывает.

## 3. Тексты ключевых блоков

**Hero**
- H1: «Дезинфекция и уборка с ценой, которую вы знаете до начала работ»
- Подзаголовок: «Оценщик бесплатно приедет, посмотрит помещение и зафиксирует стоимость в договоре. Мастера с сертификатами сделают работу в удобное вам время.»
- CTA: «Вызвать оценщика бесплатно» и «Рассчитать стоимость»
- Микротекст: «Выезд в пределах КАД — 0 ₽. Если цена не подошла, вы ничего не платите.»

**Как это работает:**
1. Заявка или звонок.
2. Выезд в удобное время.
3. Оценка и счёт.
4. Согласование.
5. Работа.
6. Приёмка и отзыв.

**Снятие возражений:**
- «Оценщик — специалист, не продавец: получает фиксированную оплату за выезд, а не процент от заказа.»
- «Цена фиксируется после оценки. Доплаты — только с вашего письменного согласия.»
- «Выезд ни к чему не обязывает. Оценщик не навязывает услуги.»
- «Оплата после приёмки. Предоплата не нужна.»
- «Это показатель чистоты поверхности, а не медицинская гарантия» (под графиком АТФ).

**Финальный CTA:** «Узнайте точную цену, не рискуя ни рублём».

**FAQ** (тексты в `src/data/mock.js → FAQ`):
- безопасность для детей и животных;
- сколько сохнет;
- нужно ли уезжать;
- что если цена не устроит;
- может ли цена вырасти;
- гарантия;
- оплата.

**Этика.** Приёмы влияния используются честно:
- дефицит считается из реальных слотов;
- срок акции настоящий, после окончания блок скрывается;
- рейтинг учитывает низкие оценки;
- среди отзывов есть оценки 2★ и 3★ с ответами компании;
- бейдж «Проверенный клиент» означает, что отзыв оставлен по ссылке из акта;
- медицинских обещаний на сайте нет.

## 4. Дизайн-система

**Цвета** (`src/index.css → @theme`):

| Токен | HEX | Роль |
|---|---|---|
| `ink` | #0E2730 | основной текст |
| `ink-soft` / `ink-mute` | #3E5A64 / #5E7780 | вторичный текст (контраст AA на белом) |
| `brand-700` / `brand-900` | #0B4A6F / #072F47 | бренд, доверие, тёмные блоки |
| `leaf-500` / `leaf-700` | #12A37A / #0B7457 | безопасность, результат, «да» |
| `amber-cta` | #FFB547 | **только** главное действие, текст на нём `ink` (контраст ≈ 10:1) |
| `mist` / `line` | #F2F7F8 / #DCE7EA | фоны секций, границы |
| `danger`, `warn` | #B42318, #8A5A00 | ошибки, предупреждения |

**Шрифты:**
- Unbounded — заголовки;
- Golos Text — текст и интерфейс (шрифт создан для русского языка);
- JetBrains Mono — цифры, цены, RLU, метки.

Базовый кегль 17 px, H1 — 34–50 px.

**Компоненты:** `.btn-cta`, `.btn-dark`, `.btn-ghost`, `.chip` (сегменты и фильтры, состояние через `aria-pressed` / `aria-checked`), `.field` (состояние ошибки через `aria-invalid`), `.card`, `.eyebrow`, `.demo-tag`, `Stars`, `Avatar`, `Spinner`.

**Состояния:**
- hover и focus-visible: обводка 3 px `brand-500`;
- disabled;
- загрузка: спиннер на карте, в проверке адреса и при отправке формы;
- пустое состояние в отзывах с кнопкой сброса фильтров;
- ошибки формы: текст под полем, фокус переходит на первое ошибочное поле;
- ошибка сети с телефоном для связи;
- экран успеха с планом «что дальше».

**Доступность:**
- семантические `section`, `nav`, `header`, `footer`;
- skip-link;
- `aria-live` для цены и результатов фильтров;
- выбор района дублируется в `select` (на карте он не только мышью);
- `prefers-reduced-motion`;
- кнопки не ниже 44–48 px.

## 5. Код

```
src/
  main.jsx            — точка входа, стили Leaflet
  App.jsx             — порядок секций, общее состояние (LeadContext)
  index.css           — Tailwind 4 + токены + компоненты
  data/mock.js        — ВСЕ демо-данные: тарифы, зоны, слоты, отзывы, команда, FAQ, графики
  lib/utils.js        — расчёт цены, маска телефона, гео (зона по точке), слоты, форматирование
  lib/store.js        — контекст для передачи выбора в форму
  components/
    Header.jsx, Hero.jsx, TrustAndSteps.jsx, Services.jsx,
    Calculator.jsx (Recharts LineChart),
    CoverageMap.jsx (Leaflet: сектора-округа, попапы, клик по карте, проверка адреса, слоты),
    Stats.jsx (3 графика: АТФ, рейтинг/повторные, распределение — кликабельно, фильтрует отзывы),
    Reviews.jsx, LeadForm.jsx (3 шага, валидация, маска, согласие, антиспам), Bottom.jsx (команда, FAQ, CTA, футер, sticky-CTA)
```

**Формула калькулятора** (`lib/utils.js → estimate`):

площадь со ступенчатой скидкой × ставка ₽/м² × коэффициент загрязнения × коэффициент срочности, минус сезонная скидка.

- Ступени площади: до 100 м² — 100% ставки, 100–300 м² — 85%, больше 300 м² — 75%.
- Коэффициент загрязнения: 1 / 1,35 / 1,8.
- Коэффициент срочности: 1 / 1,1 / 1,25.
- Минимальный заказ — 4 500 ₽.
- Результат показывается вилкой ±12%.
